Level 15: The H-lens and what the runs found

One derivative above the J-lens: the objects, the theorems that say what each estimator really measures, and a plain account of every test run on Qwen3.6-27B.

By the end of this level you can
  • define every object of the H-lens: the objective \(F_c\), the Hessian blocks \(H_{pq}\), the lens \(T_\ell\), whitening \(\tilde H = \Sigma^{1/2} H \Sigma^{1/2}\) and the random covectors \(c\);
  • prove Proposition 0 (\(M^{\text{row}} \succeq M^{\text{diag}} \succeq M^{\text{lens}}\)) and say which of these each sign-probe estimator converges to (Proposition 6);
  • read the run-1 C0 to C6 table and say exactly why it is a FAIL;
  • explain heavy tails, the Σ prior (Proposition 8) and the exact sign-flip test (Corollary 8.1), each with its proof;
  • follow v5, the Σ-orbit twin test, v8 and v9, and list precisely what is and is not established.

Prerequisites: Level 9 (Hessian, eigenvectors), Level 11 (HVPs), Level 12 (second-order adjoint, rectangle identity), Level 13 (covariance, whitening, PCA, split-half, heavy tails, sign tricks, randomization tests), Level 14 (transformers, residual stream, J-lens).

Conventions on this page
  • Vectors are plain letters (\(v\), \(c\), \(\xi\)), not bold, to match the research notes hlens/paper/theory-v2.md. Matrices are capitals.
  • Two units. Residual-stream numbers have an arbitrary unit; call it the activation unit (a.u.). The objective \(F_c\) (defined in 15.2) is an activation read along a token's unembedding row; call its unit the proxy unit (pu), which is one a.u. times one logit. Whitened coordinates are pure numbers: they count standard deviations.
  • Two clashes avoided. The identity matrix is \(I_d\) (with its size); a plain \(I\) is always an interaction, in nats. The test statistic of a randomization test is \(\tau\) (theory-v2 writes \(T\)), because \(T\) already means the window length.
  • Sources. Every number about the real runs is either printed live from assets/hspace_numbers.js (generated from results/*.json) or quoted from a named file, with the file given in small print.

15.1 Where we stand: one derivative above the J-lens

At Level 14 you met the J-lens. In theory-v2's notation it is

$$ J_\ell = \mathbb{E}_x \operatorname*{mean}_{p\in V} \frac{\partial}{\partial h_\ell[p]} \sum_{p'\in V} h_{L^*}[p'] \qquad (d\times d). $$

It answers a first-order question. If I nudge the residual at layer \(\ell\) along a direction, how does the final residual move, to first order? Directions that move it a lot, in ways that decode to tokens, form J-space.

A first-order lens cannot see an AND. Take the SwiGLU neuron of Level 14: \(\text{silu}(a\cdot x)\,(b\cdot x)\). If the gate read \(a\cdot x\) is closed, nudging the up read \(b\cdot x\) does almost nothing. Nudging both together does something. That joint effect lives in the mixed second derivative, so it lives in the Hessian. H-space asks: is there a low-dimensional subspace where the model's second-order computation lives?

The rest of this level builds the object that answers that question, proves what the estimators measure, and then walks through every test in the order it was run.

15.2 The objective and the per-context Hessian blocks

Fix a covector \(c\) (a readout direction, unit pu per a.u.). Define the objective

$$ F_c(h_\ell) = \sum_{p'\in V} c\cdot h_{L^*}[p'] \quad\text{(pu)}. $$

Read it as: run the model from layer \(\ell\) to the last block, read every valid position's final residual along \(c\), and add the results. It is a linear readout before the final norm. That is the same choice the J-lens makes.

The pre-norm proxy, not the logit For a token \(t\), \(u_t\cdot h_{L^*} = \operatorname{rms}(h_{L^*})\cdot\text{logit}_t\). So \(T_\ell[u_t]\) (defined below) is the averaged Hessian of this pre-norm proxy, not of \(\text{logit}_t\). The curvature added by the final norm is left out by construction (theory-v2 §0).

In one context \(x\), the Hessian of \(F_c\) with respect to the whole layer-\(\ell\) state is a big matrix \(H_x[c]\). Cut it into \(d\times d\) blocks, one per pair of positions:

$$ H_{pq} = \frac{\partial^2 F_c}{\partial h_\ell[p]\,\partial h_\ell[q]}, \qquad (H_{pq})_{ij} = \frac{\partial^2 F_c}{\partial h_\ell[p]_i\,\partial h_\ell[q]_j}\quad(\text{pu per a.u.}^2). $$

Two facts follow from symmetry of mixed partials (Level 6).

  1. \(H_{qp} = H_{pq}^\top\). Proof: \((H_{qp})_{ji} = \partial^2F_c/\partial h_\ell[q]_j\partial h_\ell[p]_i = \partial^2F_c/\partial h_\ell[p]_i\partial h_\ell[q]_j = (H_{pq})_{ij}\).
  2. \(H_{pp}\) is symmetric: set \(q = p\) in fact 1.

A diagonal block \(H_{pp}\) says how two moves at the same position interact. An off-diagonal block \(H_{pq}\), \(p\ne q\), says how a move at \(p\) interacts with a move at \(q\), for example through attention.

Worked example: blocks of a tiny objective

Take \(d = 2\) and two valid positions, \(V = \{1, 2\}\). Write \(h[1] = (h[1]_1, h[1]_2)\) and \(h[2] = (h[2]_1, h[2]_2)\), in a.u. Suppose, in one context, the objective happens to be (a toy, made up)

$$ F = 3\,h[1]_1\,h[2]_1 + 2\,h[1]_1\,h[1]_2 + h[2]_2^2 \quad\text{(pu; coefficients in pu per a.u.}^2). $$

Differentiate twice, one pair of coordinates at a time.

  • \(H_{11}\): only the term \(2h[1]_1h[1]_2\) has two factors at position 1. \(\partial^2/\partial h[1]_1\partial h[1]_2\) of it is 2. No square of a position-1 coordinate appears. So \(H_{11} = \begin{pmatrix}0&2\\2&0\end{pmatrix}\).
  • \(H_{22}\): only \(h[2]_2^2\), whose second derivative in \(h[2]_2\) is 2. So \(H_{22} = \begin{pmatrix}0&0\\0&2\end{pmatrix}\).
  • \(H_{12}\): only \(3h[1]_1h[2]_1\) mixes the two positions: entry (1,1) is 3. So \(H_{12} = \begin{pmatrix}3&0\\0&0\end{pmatrix}\) and \(H_{21} = H_{12}^\top\), the same matrix here.

Every entry has unit pu per a.u.². The cross-position block \(H_{12}\) is the biggest entry, yet it is not part of the H-lens, as you will see next.

15.3 The H-lens \(T_\ell\)

Definition (theory-v2 §0) $$ T_\ell[c] = \mathbb{E}_x \operatorname*{mean}_{p\in V} H_x[c]_{pp}\qquad(\text{pu per a.u.}^2). $$ For each \(c\) it is one symmetric \(d\times d\) matrix. It is linear in \(c\), because \(F_c\) is linear in \(c\). So as a whole, \(T_\ell\) is a tensor in \(\mathbb{R}^d\otimes\operatorname{Sym}(d)\): give it a readout, get back a curvature matrix.

This is the J-lens recipe one derivative higher: average a derivative over contexts and positions. The perturbation sits at a single source position \(p\), so only the diagonal blocks \(H_{pp}\) enter. In the toy above, with one context, \(\mathbb{E}_x\) does nothing and \(\operatorname{mean}_{p\in V}\) averages the two diagonal blocks, entry by entry:

$$ T = \tfrac12(H_{11}+H_{22}) = \tfrac12\left(\begin{pmatrix}0&2\\2&0\end{pmatrix} + \begin{pmatrix}0&0\\0&2\end{pmatrix}\right) = \tfrac12\begin{pmatrix}0&2\\2&2\end{pmatrix} = \begin{pmatrix}0&1\\1&1\end{pmatrix}\ \text{pu per a.u.}^2 . $$

The large \(H_{12}\) does not appear.

15.4 Whitening, and random covectors

Raw units are arbitrary. A direction where activations barely vary can have a huge raw curvature and still never matter, because the data never move along it. So theory-v2 measures curvature per unit of natural spread.

Let \(\Sigma\) be the covariance of \(h_\ell[p]\) over the data, in a.u.². The run shrinks it slightly toward a multiple of the identity, \(\Sigma = 0.95\,\hat\Sigma + 0.05\,(\operatorname{tr}\hat\Sigma/d)\,I_d\) (hlens/hspace.py, line 258), so it is safely invertible. Then

$$ \tilde H = \Sigma^{1/2} H\, \Sigma^{1/2}\qquad(\text{pu}). $$
Why this is “curvature per 1σ” Let \(\xi\) be a whitened direction (pure numbers) and \(v = \Sigma^{1/2}\xi\) the matching raw move (a.u.). Then $$ v^\top H v = (\Sigma^{1/2}\xi)^\top H (\Sigma^{1/2}\xi) = \xi^\top (\Sigma^{1/2})^\top H\,\Sigma^{1/2}\xi = \xi^\top \Sigma^{1/2} H \Sigma^{1/2}\xi = \xi^\top\tilde H\xi. $$ The second equals sign uses \((AB)^\top = B^\top A^\top\). The third uses that \(\Sigma^{1/2}\) is symmetric. So \(\tilde H\) gives the curvature of \(F_c\) along moves measured in standard deviations. Its unit is pu, because a.u.² from \(\Sigma^{1/2}\cdots\Sigma^{1/2}\) cancels the a.u.² in the denominator of \(H\).

Worked example: whitening changes which direction is “top”

Take \(\Sigma = \begin{pmatrix}4&0\\0&1\end{pmatrix}\) a.u.² and \(H = \begin{pmatrix}1&1\\1&1\end{pmatrix}\) pu per a.u.². Then \(\Sigma^{1/2} = \operatorname{diag}(2,1)\) a.u., and

$$ \tilde H = \begin{pmatrix}2&0\\0&1\end{pmatrix}\begin{pmatrix}1&1\\1&1\end{pmatrix}\begin{pmatrix}2&0\\0&1\end{pmatrix} = \begin{pmatrix}2&2\\1&1\end{pmatrix}\begin{pmatrix}2&0\\0&1\end{pmatrix} = \begin{pmatrix}4&2\\2&1\end{pmatrix}\ \text{pu}. $$
  • Raw: \(H\) has eigenvalues 2 and 0. Its top eigenvector is \((1,1)/\sqrt2\), at 45°.
  • Whitened: \(\operatorname{tr}\tilde H = 5\) and \(\det\tilde H = 4 - 4 = 0\), so the eigenvalues are 5 and 0. The top eigenvector solves \((\tilde H - 5I_2)w = 0\): \(-w_1 + 2w_2 = 0\), so \(w = (2,1)/\sqrt5\) in whitened coordinates.

Mapped back to raw coordinates (a whitened direction \(w\) is the raw move \(\Sigma^{1/2}w\)): \(\operatorname{diag}(2,1)\,(2,1) = (2\times2,\ 1\times1) = (4, 1)\), up to the factor \(1/\sqrt5\). That is about 14° from the first axis, against 45° before: the top direction has tilted toward the high-variance axis. Whitening is, in theory-v2's words, “a choice, not a consequence”. Hold this thought: in 15.10 it becomes the Σ prior.

Random covectors

One readout \(c\) asks about one token mixture. To ask about all tokens at once, theory-v2 draws \(c\sim\mathcal N(0,\Sigma_U)\) with \(\Sigma_U = \frac{1}{|\text{vocab}|}\sum_t u_tu_t^\top\). Any quantity quadratic in \(c\) then averages as if every vocabulary token were weighted equally: \(\mathbb{E}[cc^\top] = \Sigma_U\).

15.5 Three energy operators, and Proposition 0

Why not just take the top eigenvectors of \(T_\ell[c]\)? Because signed curvature cancels. On 0.8B, a corpus-averaged signed H-lens predicted per-context interactions at only \(r\approx 0.3\) (paper §3.2, “Reading 2”). The same direction curves up in one context and down in another. So H-space is defined by energy: squares, which cannot cancel. There are three natural ways to square.

The three operators (theory-v2 §0), all \(d\times d\), all in pu² $$ M^{\text{lens}}_\ell = \mathbb{E}_c\big[\tilde T_\ell[c]^2\big] \qquad\text{(square the average)} $$ $$ M^{\text{diag}}_\ell = \mathbb{E}_{x,c}\operatorname*{mean}_{p\in V}\tilde H_{pp}^2 \qquad\text{(average the squares of diagonal blocks)} $$ $$ M^{\text{row}}_\ell = \mathbb{E}_{x,c}\operatorname*{mean}_{p\in V}\sum_{q\in V}\tilde H_{pq}\tilde H_{pq}^\top \qquad\text{(whole row of blocks, cross-position included)} $$

Each is positive semidefinite. Why, in steps:

Step 1: every piece has the form \(AA^\top\). \(\tilde H_{pq}\tilde H_{pq}^\top\) is already of that form. For the symmetric \(\tilde H_{pp}\) and \(\tilde T[c]\), \(\tilde H_{pp}^\top = \tilde H_{pp}\), so \(\tilde H_{pp}^2 = \tilde H_{pp}\tilde H_{pp}^\top\), and likewise for \(\tilde T[c]^2\).

Step 2: such a piece is never negative along any \(w\). \(w^\top AA^\top w = (A^\top w)^\top(A^\top w)\), because \((A^\top w)^\top = w^\top A\) (transpose of a product, reversed). That is the squared length \(\lVert A^\top w\rVert^2 \ge 0\).

Step 3: averages keep the sign. By linearity, \(w^\top(\text{average of pieces})\,w\) is the average of the numbers \(w^\top(\text{piece})\,w\), each \(\ge 0\). Toy: \(A = \begin{pmatrix}1&2\\0&0\end{pmatrix}\), \(w = (1, -1)\): \(A^\top w = (1, 2)\), so \(w^\top AA^\top w = 1 + 4 = 5 \ge 0\).

Proposition 0 (ordering)

In words. Adding the cross-position blocks can only add energy. Squaring before averaging can only give more energy than averaging before squaring. So row energy dominates diagonal energy, which dominates lens energy, in every direction and for every sorted eigenvalue. But the three top-\(k\) subspaces can still point in different directions.

In symbols.

$$ M^{\text{row}} - M^{\text{diag}} = \mathbb{E}_{x,c}\operatorname*{mean}_p\sum_{q\ne p}\tilde H_{pq}\tilde H_{pq}^\top \succeq 0,\qquad M^{\text{diag}} - M^{\text{lens}} = \mathbb{E}_c\,\mathbb{E}_{x,p}\big[(\tilde H_{pp}-\tilde T[c])^2\big]\succeq 0, $$ $$ \text{hence}\quad M^{\text{row}}\succeq M^{\text{diag}}\succeq M^{\text{lens}}\quad\text{and}\quad \lambda_i(M^{\text{row}})\ge\lambda_i(M^{\text{diag}})\ge\lambda_i(M^{\text{lens}})\ \text{for every } i. $$

Proof, line by line.

  1. First gap. In \(M^{\text{row}}\) split the sum over \(q\) into \(q = p\) and \(q\ne p\). The \(q = p\) term is \(\tilde H_{pp}\tilde H_{pp}^\top = \tilde H_{pp}^2\), whose average is \(M^{\text{diag}}\). What remains is the stated difference. Each \(\tilde H_{pq}\tilde H_{pq}^\top\) is positive semidefinite, and sums and averages of positive semidefinite matrices are positive semidefinite.
  2. Second gap: fix \(c\). Let \(A = \tilde H_{pp}\) where \((x, p)\) is random: \(x\) from the corpus, \(p\) uniform on \(V\). Its mean is \(\mathbb{E}A = \mathbb{E}_x\operatorname{mean}_p\Sigma^{1/2}H_{pp}\Sigma^{1/2} = \Sigma^{1/2}T_\ell[c]\Sigma^{1/2} = \tilde T[c]\), because whitening is linear and passes through averages.
  3. Expand \((A - \mathbb{E}A)^2 = A^2 - A\,\mathbb{E}A - \mathbb{E}A\,A + (\mathbb{E}A)^2\). (Matrices need not commute, so keep the order.)
  4. Take the expectation of each of the four terms (linearity). \(\mathbb{E}A\) is a fixed matrix, so it comes outside: \(\mathbb{E}[A\,\mathbb{E}A] = (\mathbb{E}A)(\mathbb{E}A) = (\mathbb{E}A)^2\), and the same for \(\mathbb{E}[\mathbb{E}A\,A]\). The last term is fixed already. So \(\mathbb{E}[(A-\mathbb{E}A)^2] = \mathbb{E}[A^2] - (\mathbb{E}A)^2 - (\mathbb{E}A)^2 + (\mathbb{E}A)^2 = \mathbb{E}[A^2] - (\mathbb{E}A)^2\). Toy with \(d = 1\): \(A = 1\) or \(3\), equally likely. \(\mathbb{E}A = 2\), \(\mathbb{E}[A^2] = (1 + 9)/2 = 5\), and \(\mathbb{E}[(A - 2)^2] = (1 + 1)/2 = 1 = 5 - 4\).
  5. \(A - \mathbb{E}A\) is symmetric, so \((A-\mathbb{E}A)^2 = (A-\mathbb{E}A)(A-\mathbb{E}A)^\top\succeq 0\), and so is its expectation.
  6. So \(\mathbb{E}_{x,p}[\tilde H_{pp}^2] - \tilde T[c]^2\succeq 0\). Average over \(c\): \(M^{\text{diag}} - M^{\text{lens}}\succeq 0\).
  7. Eigenvalues (Weyl monotonicity). By the Courant–Fischer theorem, \(\lambda_i(A) = \max_{\dim U = i}\ \min_{w\in U,\lVert w\rVert = 1} w^\top Aw\). If \(A\succeq B\) then \(w^\top Aw\ge w^\top Bw\) for every \(w\), so every inner minimum, and hence every maximum, is at least as large for \(A\). So \(\lambda_i(A)\ge\lambda_i(B)\). ∎
What Proposition 0 does not say It orders eigenvalues and traces. It says nothing about eigenvectors. Run 1 estimated \(M^{\text{row}}\) (Prop. 6a below). Its top-25 need not resemble the top-25 of \(M^{\text{diag}}\) or \(M^{\text{lens}}\). Every H-space claim must name its \(M\).

15.6 H-space\(_k\), and how a subspace is judged

Definition H-space\(_k(M)\) is the span of the top-\(k\) eigenvectors of a chosen energy operator \(M\). The default is \(k = 25\), matching J-space's “at most 25 active directions”. H25 means H-space\(_{25}\) of the run-1 operator.

Three yardsticks from Level 13 are used throughout.

  • Overlap. For two \(d\times k\) orthonormal bases \(A, B\), \(\operatorname{ov}(A,B) = \lVert A^\top B\rVert_F^2/k\), the mean squared cosine. Identical subspaces give 1. Two random \(k\)-subspaces give about \(k/d\): ... for \(k = 25\), \(d = 5120\).
  • split@\(k\). Split the probes into two disjoint halves, estimate \(M\) on each, and take the overlap of the two top-\(k\) subspaces. It measures reproducibility.
  • Participation ratio. \(\text{PR} = (\sum_i\lambda_i)^2/\sum_i\lambda_i^2\). If \(m\) eigenvalues are equal and the rest zero, PR = \(m\). It counts how many directions carry the energy.

15.7 Sign probes, and what each estimator converges to (Proposition 6)

You cannot write down a 5,120 × 5,120 matrix per position per context (Level 11). You can compute Hessian-vector products. The run-1 probe design (theory-v2 §6A) is:

  1. Draw one covector \(c\sim\mathcal N(0,\Sigma_U)\).
  2. Draw one whitened direction \(\xi\sim\mathcal N(0,I_d)\) and set \(v = \Sigma^{1/2}\xi\) (a.u.).
  3. Draw Rademacher signs \(s_p\) for every valid position of every window.
  4. Compute one HVP, \(g = H(s\otimes v)\) (theory-v2 writes \(h\); here \(h\) is kept for the residual state), where \(s\otimes v\) puts \(s_pv\) at position \(p\). The Hessian is block-diagonal over windows, because windows are separate forward passes.

The HVP output and the stored sample (“row”), one step at a time.

Step 1: block multiplication. The tangent has block \(s_qv\) at position \(q\). Block \(p\) of \(H\) times it is the sum over \(q\) of block \((p,q)\) times block \(q\): \(g_p = \sum_q H_{pq}(s_qv)\) (pu per a.u.).

Step 2: move the sign out and substitute \(v\). \(s_q\) is a number, so it can move to the front. With \(v = \Sigma^{1/2}\xi\): \(g_p = \sum_q s_q H_{pq}\Sigma^{1/2}\xi\).

Step 3: the stored row. The code stores \(y_p = \Sigma^{1/2}s_pg_p\). Put in Step 2, and move the numbers \(s_p\), \(s_q\) to the front:

$$ y_p = \Sigma^{1/2}s_p g_p = s_p\sum_{q\in V}s_q\,\Sigma^{1/2}H_{pq}\Sigma^{1/2}\xi . $$

Step 4: recognise the whitened block. \(\Sigma^{1/2}H_{pq}\Sigma^{1/2} = \tilde H_{pq}\), so

$$ y_p = s_p\sum_{q\in V}s_q\,\tilde H_{pq}\,\xi\qquad(\text{pu}). $$

Toy with \(d = 1\) (blocks are numbers) and two positions: \(\tilde H_{11} = 1\), \(\tilde H_{12} = 2\), \(\xi = 1\), \(s = (+1, -1)\). Then \(y_1 = (+1)\big((+1)\times1 + (-1)\times2\big)\times1 = -1\).

One HVP gives \(|V|\) rows per window. Run 1 used 256 probes × \(B = 4\) windows per layer, \(T = 128\), \(|V| = 111\) (theory-v2 §6A). Everything below is conditional on the plug-in \(\mu\) and \(\Sigma\).

Proposition 6 (simplified)

In words. Each estimator is an average of some product of rows. Which energy operator it converges to depends on how many independent sign vectors it uses. One sign vector cannot tell a same-position block from a cross-position block, so it converges to the whole row energy. Two independent sign vectors cancel the cross-position blocks in expectation, so their cross product converges to the diagonal energy.

In symbols.

  • (a) One sign vector (run 1; loc_raw): \(\mathbb{E}[y_py_p^\top] = \sum_{q\in V}\tilde H_{pq}\tilde H_{pq}^\top\). Averaged over \(x, c, p\), the estimator converges to \(M^{\text{row}}\).
  • (b) Two independent sign vectors \(s^1, s^2\), same \(\xi\) (loc_x): \(\mathbb{E}[y^1_p\mid\xi] = \tilde H_{pp}\xi\) and \(\mathbb{E}[\tfrac12(y^1_py^{2\top}_p + y^2_py^{1\top}_p)] = \tilde H_{pp}^2\). It converges to \(M^{\text{diag}}\). It costs 2 HVPs per probe and is unbiased, but each sample is indefinite, so finite estimates carry negative eigen-mass.
  • (c) Two independent rectangle points (int_x) converge to \(M^{\text{rect}} = \mathbb{E}\operatorname{mean}_{p\in P}(\bar{\tilde H}_{pp})^2\), the diagonal energy of the Lemma-3 rectangle-averaged Hessian (Level 12). Still an energy over random pairs, not a pair-specific form.
  • (d) One rectangle point (int_raw): the mean row energy at a random rectangle point, which is neither the averaged Hessian nor its energy.
  • (e) Spatial-sign variants (norm: \(\mathbb{E}[\hat y\hat y^\top]\); xnorm: its two-sign-vector version) have no closed form in \(H\). Their eigenvectors equal those of \(\mathbb{E}[yy^\top]\) only if the rows are elliptically distributed, which a mixture over contexts, positions and covectors need not be.
  • (f) Run 1's “\(M_{\text{lens}}\)” (rows averaged over a probe's \(B\) windows and \(|V|\) positions before squaring) converges to \(M^{\text{lens}} + \tfrac1B\mathbb{E}_c\operatorname{Cov}_x(\operatorname{mean}_p\tilde H_{pp}) + \tfrac{1}{B|V|^2}\mathbb{E}\sum_{p\lt q}S_{pq}S_{pq}^\top\), with \(S_{pq} = \tilde H_{pq} + \tilde H_{qp}\). Neither bias term shrinks with more probes.

Proof of (a), line by line. Fix \(x\), \(c\) and \(p\). The randomness is in \(s\) and \(\xi\), which are independent.

  1. Transpose the row. The transpose of a product is the product of the transposes in reverse order, and numbers are unchanged: \(y_p^\top = s_p\sum_{q'}s_{q'}\,\xi^\top\tilde H_{pq'}^\top\). (A second index name \(q'\) keeps the two sums apart.)
  2. Multiply the column \(y_p\) by the row \(y_p^\top\). Every term of the first sum meets every term of the second: \(y_py_p^\top = s_p^2\sum_q\sum_{q'}s_qs_{q'}\,\tilde H_{pq}\,\xi\xi^\top\,\tilde H_{pq'}^\top\).
  3. \(s_p^2 = 1\), because \(s_p = \pm1\).
  4. Take the expectation term by term (linearity). In each term the random parts are \(s_qs_{q'}\) and \(\xi\xi^\top\), which are independent, so the mean of their product is the product of their means: \(\mathbb{E}[s_qs_{q'}]\,\tilde H_{pq}\,\mathbb{E}[\xi\xi^\top]\,\tilde H_{pq'}^\top\).
  5. \(\mathbb{E}[s_qs_{q'}] = 1\) if \(q = q'\) (because \(s_q^2 = 1\)) and \(0\) otherwise (independent signs with mean 0, Level 13). This holds also when \(q\) or \(q'\) equals \(p\). So only the terms with \(q' = q\) survive.
  6. \(\mathbb{E}[\xi\xi^\top] = I_d\): the covariance of \(\mathcal N(0, I_d)\).
  7. So \(\mathbb{E}[y_py_p^\top] = \sum_q\tilde H_{pq}I_d\tilde H_{pq}^\top = \sum_q\tilde H_{pq}\tilde H_{pq}^\top\). Average over \(x, c, p\): \(M^{\text{row}}\). ∎

Toy check with the \(d = 1\) toy above (\(\tilde H_{11} = 1\), \(\tilde H_{12} = 2\), \(\xi = 1\) fixed): the four sign patterns give \(y_1 = s_1(s_1 + 2s_2) = 1 + 2s_1s_2\), that is 3, −1, −1, 3. Their squares 9, 1, 1, 9 average 5, which is \(1^2 + 2^2\).

Proof of (b).

  1. Hold \(\xi\) fixed and average over the signs \(s^1\) only (written \(\mathbb{E}[\,\cdot\mid\xi]\)). By linearity, \(\mathbb{E}[y^1_p\mid\xi] = \sum_q\mathbb{E}[s^1_ps^1_q]\,\tilde H_{pq}\xi\).
  2. \(\mathbb{E}[s^1_ps^1_q] = \delta_{pq}\), where \(\delta_{pq}\) is 1 if \(p = q\) and 0 otherwise (Level 13). Only the \(q = p\) term survives: \(\mathbb{E}[y^1_p\mid\xi] = \tilde H_{pp}\xi\). The same holds for \(y^2_p\).
  3. Given \(\xi\), \(y^1_p\) and \(y^2_p\) are independent (different sign vectors). For independent quantities, the mean of a product is the product of the means: \(\mathbb{E}[y^1_py^{2\top}_p\mid\xi] = \mathbb{E}[y^1_p\mid\xi]\,\mathbb{E}[y^2_p\mid\xi]^\top = \tilde H_{pp}\xi\,(\tilde H_{pp}\xi)^\top\).
  4. Transpose the product, reversed: \((\tilde H_{pp}\xi)^\top = \xi^\top\tilde H_{pp}^\top\). So the conditional mean is \(\tilde H_{pp}\xi\xi^\top\tilde H_{pp}^\top\).
  5. Average over \(\xi\), using \(\mathbb{E}[\xi\xi^\top] = I_d\): \(\tilde H_{pp}I_d\tilde H_{pp}^\top = \tilde H_{pp}\tilde H_{pp}^\top\). Since \(\tilde H_{pp}\) is symmetric, that is \(\tilde H_{pp}^2\).
  6. The symmetrised version \(\tfrac12(y^1_py^{2\top}_p + y^2_py^{1\top}_p)\): its second term is the transpose of the first, so its mean is \((\tilde H_{pp}^2)^\top = \tilde H_{pp}^2\). The average of the two is \(\tilde H_{pp}^2\). Average over \(x, c, p\): \(M^{\text{diag}}\). ∎
Proof of (f), for completeness

Step 1: sum one window's rows. From the row formula, \(\sum_py_p = \sum_p\sum_qs_ps_q\tilde H_{pq}\xi\).

Step 2: the terms with \(q = p\). \(s_p^2 = 1\), so they give \(\sum_p\tilde H_{pp}\xi = |V|\,A\,\xi\), with \(A = \operatorname{mean}_p\tilde H_{pp}\) (a sum is \(|V|\) times the mean).

Step 3: the terms with \(q \ne p\). Each unordered pair \(p\lt q\) appears twice, as \((p,q)\) and \((q,p)\), with the same sign product \(s_ps_q\). Together they give \(s_ps_q(\tilde H_{pq} + \tilde H_{qp})\xi = s_ps_qS_{pq}\xi\).

Step 4: divide by \(|V|\). \(\frac{1}{|V|}\sum_py_p = A\xi + \frac{1}{|V|}\sum_{p\lt q}s_ps_qS_{pq}\xi\).

Step 5: average over the \(B\) windows of the probe (same \(c\), same \(\xi\), each window \(\beta = 1,\dots,B\) with its own signs and blocks, marked by a superscript \((\beta)\)):

$$ \bar y = \bar A\xi + \Omega\xi, \qquad \bar A = \frac1B\sum_\beta A_\beta, \qquad \Omega = \frac{1}{B|V|}\sum_\beta\sum_{p\lt q}s^{(\beta)}_ps^{(\beta)}_qS^{(\beta)}_{pq} . $$

Step 6: square. \(\bar y\bar y^\top = \bar A\xi\xi^\top\bar A^\top + \bar A\xi\xi^\top \Omega^\top + \Omega\xi\xi^\top\bar A^\top + \Omega\xi\xi^\top \Omega^\top\) (transpose of a product, reversed).

Step 7: the two mixed terms vanish. Each is linear in sign products \(s_ps_q\) with \(p \ne q\), which average 0 and are independent of everything else.

Step 8: the last term. It is a double sum over pairs of (window, pair) of \(s^{(\beta)}_ps^{(\beta)}_q\,s^{(\beta')}_{p'}s^{(\beta')}_{q'}\) times matrices. The four-sign product averages 1 when it is the same window and the same pair (every sign then appears squared), and 0 otherwise (some sign appears once, and its mean is 0). With \(\mathbb{E}[\xi\xi^\top] = I_d\), the survivors give \(\frac{1}{B^2|V|^2}\sum_\beta\sum_{p\lt q}S^{(\beta)}_{pq}S^{(\beta)\top}_{pq}\). The \(B\) windows have the same law, so the average is \(\frac{B}{B^2|V|^2}\,\mathbb{E}\sum_{p\lt q}S_{pq}S_{pq}^\top = \frac{1}{B|V|^2}\,\mathbb{E}\sum_{p\lt q}S_{pq}S_{pq}^\top\).

Step 9: the first term. With \(\mathbb{E}[\xi\xi^\top] = I_d\) and \(\bar A\) symmetric, it averages \(\mathbb{E}[\bar A^2]\). Write \(\bar A = \mathbb{E}A + (\bar A - \mathbb{E}A)\) and square. The mixed terms average 0, because \(\bar A - \mathbb{E}A\) averages 0. So \(\mathbb{E}[\bar A^2] = (\mathbb{E}A)^2 + \mathbb{E}[(\bar A - \mathbb{E}A)^2]\).

Step 10: the variance of a mean of \(B\) independent windows. \(\bar A - \mathbb{E}A = \frac1B\sum_\beta(A_\beta - \mathbb{E}A)\). Squaring gives \(B^2\) terms over \(B^2\); the \(\beta \ne \beta'\) ones average 0 by independence, and the \(B\) others average \(\operatorname{Cov}_x(A)\) each. So \(\mathbb{E}[(\bar A - \mathbb{E}A)^2] = \frac{B}{B^2}\operatorname{Cov}_x(A) = \frac1B\operatorname{Cov}_x(A)\). This is the matrix version of \(\sigma^2/n\) (Level 13).

Step 11: collect. \((\mathbb{E}A)^2 = \tilde T[c]^2\) (Proposition 0, step 2). Adding Steps 8 to 10 and averaging over \(c\) gives \(M^{\text{lens}} + \tfrac1B\mathbb{E}_c\operatorname{Cov}_x(A) + \tfrac{1}{B|V|^2}\mathbb{E}\sum_{p\lt q}S_{pq}S_{pq}^\top\). ∎

15.9 Run 2, the v3 test, and heavy tails (Observation 8.2)

Run 2 (paper §4b) re-estimated the per-position energy at the same four layers with four estimators: raw (one sign vector, → \(M^{\text{row}}\)), cross-moment x (two sign vectors, → \(M^{\text{diag}}\)), spatial sign norm, and spatial-sign cross-moment xnorm. 256 probes × 4 windows per layer; 64 rows per probe were kept for offline tests. It was designed after seeing run 1, so it is exploratory except where a new preregistration governs it.

v3 (SCOPE-hspace-v3.md, frozen before run-2 data existed) fixed C1 by measuring reliability at the signal dimension:

  • Noise floor = \(|\lambda_{\min}|\) of the signed cross-moment matrix. The population matrix \(M^{\text{diag}}\) is positive semidefinite, so any negative eigenvalue is pure sampling noise, and any positive eigenvalue below that size is indistinguishable from noise.
  • \(k_{\text{floor}}\) = min(25, number of eigenvalues above the floor in each half). C1′ passes if \(k_{\text{floor}}\ge 3\), split@\(k_{\text{floor}}\ge 0.7\) and split@5 ≥ 0.7.

v3 verdict: not found. The primary loc_x fails C1′ at all four layers: split@25 is 0.13 / 0.15 / 0.17 / 0.29, and the counts of eigenvalues above the floor are 0 / 2 / 5 / 2 of 5,120 at L16 / L28 / L40 / L52, so \(k_{\text{floor}} = 1\) everywhere (paper §4b; corrected count in results/CORRECTIONS.md, Oct 6 ~18:29).

Observation 8.2: heavy tails explain C1 and C1′

Each run-2 row \(y_p\) is one (position, probe) sample. Sort the rows by their squared length \(\lVert y_p\rVert^2\). At L16, the heaviest ... rows (0.1% of ...) carry ... of the raw second moment. Digit tokens are ... of rows but ... of the energy. L28 is similarly concentrated (top 0.1%: ...), but there digits carry only ....

Consequence. An average of \(y_py_p^\top\) is then an average of about a dozen big outer products plus dust. Split the probes in half and each half gets a different handful of giants, so the top eigenvectors change between halves. That is C1 (0.33 to 0.41) and C1′. The Kish effective sample size of the rows is 0.01 to 0.06% of rows, about 2 to 10 effective rows out of 16,384 (theory-v2 Obs. 8.3).

Trimming fixes reproducibility. Dropping the heaviest 5% of rows gives raw split@5 of ... at L16, and split@25 of ... / ... at L16 / L28 (Figure 15.5).

The catch with robust estimators The spatial sign \(\hat y = y/\lVert y\rVert\) gives every row equal weight, so it is robust. But it estimates a different population object (the shape operator). Its eigenvectors equal those of the raw operator only for elliptical row laws (theory-v2 §6B). And, as the next section shows, its excellent reproducibility is mostly not about the Hessian at all.

15.10 The Σ prior (Proposition 8)

The spatial-sign estimators reproduced at 0.92 to 0.99 (paper §4b). That looked like success. Then a problem was proved: whitened curvature estimators reproduce PCA axes whenever the curvature has no preferred direction beyond what \(\Sigma\) already gives it.

Setup (theory-v2 §6B). A run-2 row is \(y_p = \sum_qs_ps_q\tilde H_{pq}z\), with \(z\sim\mathcal N(0,I_d)\) shared by every row of a probe. \(P\) is the PCA basis of \(\Sigma\). The sign-flip group is

$$ \mathcal D = \{P\operatorname{diag}(\pm1,\dots,\pm1)P^\top\}\quad(2^d\ \text{matrices}). $$

Three properties of every \(D\in\mathcal D\), each one line:

  • \(D^\top = D\) and \(D^2 = P\operatorname{diag}(\pm1)^2P^\top = PP^\top = I_d\). So \(D\) is orthogonal and its own inverse.
  • $$\begin{aligned} D\Sigma D &= P\operatorname{diag}(\pm1)P^\top\, P\operatorname{diag}(\sigma^2)P^\top\, P\operatorname{diag}(\pm1)P^\top \\ &= P\operatorname{diag}(\pm1)\operatorname{diag}(\sigma^2)\operatorname{diag}(\pm1)P^\top = \Sigma, \end{aligned}$$ because diagonal matrices commute and \((\pm1)^2 = 1\). The same holds for \(\Sigma^{1/2}\) and any function of \(\Sigma\).
  • In PCA coordinates, \(D\) just flips the signs of some coordinates.

Proposition 8

In words. Suppose that flipping the signs of any PCA axes, applied to every whitened Hessian block at once, does not change the statistical law of those blocks. Then the expected estimator matrix has no off-diagonal entries in the PCA basis. Its eigenvectors are PCA axes. This holds for all four run-2 estimators.

In symbols. If the joint law of \(\{\tilde H_{pq}\}\) (over windows and positions) is invariant under \(\tilde H\mapsto D\tilde HD\) for every \(D\in\mathcal D\), then \(\mathbb{E}[M]\) is diagonal in \(P\) for the raw, spatial-sign, cross-moment and spatial-sign cross-moment estimators.

Proof, line by line.

  1. \(z\mapsto Dz\) preserves \(\mathcal N(0,I_d)\): \(Dz\) is Gaussian with mean 0 and covariance \(DI_dD^\top = I_d\).
  2. Replace every block by \(D\tilde H_{pq}D\) and \(z\) by \(Dz\). A row becomes \(\sum_qs_ps_qD\tilde H_{pq}D\,Dz = D\sum_qs_ps_q\tilde H_{pq}z = Dy_p\), because \(D^2 = I_d\). By the hypothesis and step 1 (blocks and \(z\) are independent), the replaced inputs have the same joint law as the originals. So the rows \(\{Dy_p\}\) of a probe have the same joint law as \(\{y_p\}\).
  3. Each estimator is equivariant: \(M(Dy) = DM(y)D\). Raw: \((Dy)(Dy)^\top = Dyy^\top D\). Spatial sign: \(\lVert Dy\rVert = \lVert y\rVert\) because \(D\) is orthogonal, so \(Dy/\lVert Dy\rVert = D(y/\lVert y\rVert)\). Cross-moments: \(Dy^1(Dy^2)^\top = D\,y^1y^{2\top}D\).
  4. Steps 2 and 3 give \(\mathbb{E}[M] = \mathbb{E}[M(Dy)] = D\,\mathbb{E}[M]\,D\) for every \(D\in\mathcal D\).
  5. Write \(\mathbb{E}[M]\) in PCA coordinates: \(\Gamma = P^\top\mathbb{E}[M]P\). Choose \(D\) that flips only axis \(i\). Then \(P^\top DP = P^\top P\operatorname{diag}(\pm1)P^\top P = \operatorname{diag}(1,\dots,-1,\dots,1)\), with the \(-1\) in place \(i\), because \(P^\top P = I_d\).
  6. Sandwich step 4 between \(P^\top\) and \(P\), and insert \(PP^\top = I_d\) on both sides of \(\mathbb{E}[M]\): \(\Gamma = P^\top D\,\mathbb{E}[M]\,DP = (P^\top DP)(P^\top\mathbb{E}[M]P)(P^\top DP) = \operatorname{diag}(\ldots)\,\Gamma\,\operatorname{diag}(\ldots)\).
  7. A diagonal matrix on the left multiplies row \(i\) by its \(i\)-th entry; on the right it multiplies column \(j\) by its \(j\)-th entry. So entry \((i,j)\) becomes \((-1)\,\Gamma_{ij}\,(+1)\) for every \(j\ne i\): \(\Gamma_{ij} = -\Gamma_{ij}\). Toy with \(d = 2\), \(i = 1\): \(\begin{pmatrix}-1&0\\0&1\end{pmatrix}\begin{pmatrix}5&2\\2&3\end{pmatrix}\begin{pmatrix}-1&0\\0&1\end{pmatrix} = \begin{pmatrix}5&-2\\-2&3\end{pmatrix}\). The diagonal survives, the off-diagonal flips, so the two can only be equal if the off-diagonal entry is 0.
  8. A number equal to its own negative is 0. So every off-diagonal entry of \(\Gamma\) is 0: \(\mathbb{E}[M]\) is diagonal in \(P\). ∎

Laws that satisfy the hypothesis (theory-v2 §6B), with the one-line reason:

  • \(H = cI_d\), and any \(H = f(\Sigma)\): then \(\tilde H = \Sigma^{1/2}f(\Sigma)\Sigma^{1/2}\) is diagonal in \(P\), and \(D\tilde HD = \tilde H\) exactly.
  • GOE- or Haar-random curvature: the law of a GOE matrix \(G\) is unchanged by any orthogonal conjugation, and \(D\) commutes with \(\Sigma^{1/2}\), so \(D\tilde HD = \Sigma^{1/2}(DGD)\Sigma^{1/2}\) has the law of \(\tilde H\).
  • The isotropic RMSNorm curvature term of theory-v2 §2.
Consequences (theory-v2 §6B)
  • Under such laws, the whitened lens returns PCA-ordered directions (ranked by the diagonal of \(\mathbb{E}[M]\) in the PCA basis).
  • With many near-independent rows, it does so reproducibly. A simulated GOE-type null at the run-2 budget gave split-half 0.98 and PCA-25 overlap 0.997, with PR 52 to 125.
  • So three things are not evidence of H-specific structure: high split-half, large overlap with PCA, a flat spectrum. And \(25/d\) is the wrong baseline.

15.11 An exact test: PCA sign flips (Corollary 8.1)

Proposition 8 turns a problem into a test. If the null is “the curvature law is invariant under \(\mathcal D\)”, then flipping PCA signs does not change the law of the data. So flipped datasets are exact samples from the null.

Corollary 8.1

In words. Flip random PCA signs on every row of each probe (the same flips within a probe), recompute your statistic, and repeat \(N\) times. Under the null, the real statistic is just one more draw from the same pool, so its rank among the \(N + 1\) values gives an exact p-value.

In symbols. \(H_0\): the law of the blocks is invariant under \(\mathcal D\). For replicate \(r = 1,\dots,N\), draw one \(D\in\mathcal D\) uniformly per probe and apply it to every row of that probe. Let \(\tau_0\) be the statistic on the real data and \(\tau_r\) on replicate \(r\). Then

$$ p = \frac{1 + \#\{r : \tau_r\ge\tau_0\}}{N+1} $$

satisfies \(\Pr(p\le\alpha)\le\alpha\) under \(H_0\), for every \(\alpha\) and every statistic \(\tau\).

Proof, line by line.

  1. Write \(Y\) for the real data (all probes) and \(\mathbf D = (D^{(1)},\dots)\) for a choice of one flip per probe. The set of all such choices is a group: composing two choices or inverting one gives another choice.
  2. By step 2 of Proposition 8, applied probe by probe (probes are independent), \(\mathbf DY\) has the same law as \(Y\) for every fixed \(\mathbf D\). So it also does for a random \(\mathbf D\) drawn independently of \(Y\).
  3. Draw \(\mathbf D_0\) uniformly and set \(Y' = \mathbf D_0Y\). By step 2, \(Y'\) has the law of \(Y\); and because each \(\mathbf D\) is its own inverse, \(Y = \mathbf D_0Y'\).
  4. The real statistic is \(\tau(\mathbf D_0Y')\) and replicate \(r\) is \(\tau(\mathbf D_r\mathbf D_0Y')\). The group elements \(\mathbf D_0, \mathbf D_1\mathbf D_0,\dots,\mathbf D_N\mathbf D_0\) are independent and uniform (multiplying a uniform group element by a fixed one gives a uniform one), and independent of \(Y'\).
  5. So \((\tau_0,\tau_1,\dots,\tau_N)\) are exchangeable: \(N + 1\) values made the same way from the same \(Y'\). The rank of \(\tau_0\) among them is uniform (ties counted against \(\tau_0\), which is what the “≥” does).
  6. Name the rank. \(1 + \#\{r : \tau_r\ge\tau_0\}\) is the position of \(\tau_0\) when the \(N + 1\) values are sorted from the top, ties counted against \(\tau_0\). With no ties it is equally likely to be any of \(1, 2, \dots, N+1\). Ties can only push it down the list. So for any whole number \(m\) from 1 to \(N+1\), \(\Pr(\text{rank}\le m)\le m/(N+1)\). Toy: \(N = 3\), four exchangeable values, no ties: the real one is top with probability \(\tfrac14\), in the top two with probability \(\tfrac24\).
  7. Translate to \(p\). By definition \(p = \text{rank}/(N+1)\). So \(p\le\alpha\) means \(\text{rank}\le\alpha(N+1)\), that is \(\text{rank}\le m\) with \(m\) the largest whole number not above \(\alpha(N+1)\). Step 6 gives \(\Pr(p\le\alpha)\le m/(N+1)\le\alpha\). ∎

The “+1” in numerator and denominator counts the real data as one of the draws. With \(N = 200\), the smallest possible p-value is \(1/201\approx\) ..., which is exactly what every v5 test returned.

Which statistic: the diagonal-normalised operator

Under \(H_0\), \(\mathbb{E}[M]\) is diagonal in PCA coordinates, but its diagonal is not flat. So the raw top eigenvector is a PCA axis under the null, and split-half would be high under the null too. The fix in hlens/hs_flip5.py (header comment) is to divide out the diagonal. In PCA coordinates,

$$ R = \operatorname{diag}(M)^{-1/2}\,M\,\operatorname{diag}(M)^{-1/2}. $$

Under \(H_0\), \(R\) is close to \(I_d\) for large samples: all eigenvalues near 1, no preferred direction. Structure that is consistent across windows but not aligned with PCA axes survives as off-diagonal entries, so \(\lambda_1(R)\) rises above 1. The eigenvectors of \(R\) live in rescaled coordinates; multiplying them by \(\operatorname{diag}(M)^{1/2}\) and orthonormalising gives the patterns. split@3 is the overlap of the top-3 patterns from the two probe-parity halves.

Which preprocessing keeps the test useful

Before estimating, the run removes confounds such as the massive-activation span. How you remove them matters.

  • Axis-aligned removal (mask some PCA axes, normalise rows, keep some PCA coordinates). A mask \(K = P\operatorname{diag}(0\text{ or }1)P^\top\) commutes with every \(D\). Step 1: multiply, using \(P^\top P = I_d\) in the middle: \(KD = P\operatorname{diag}(0\text{ or }1)\operatorname{diag}(\pm1)P^\top\) and \(DK = P\operatorname{diag}(\pm1)\operatorname{diag}(0\text{ or }1)P^\top\). Step 2: diagonal matrices commute (their product just multiplies matching diagonal entries, and \(0\times(-1) = (-1)\times0\), \(1\times(-1) = (-1)\times1\)), so \(KD = DK\), and \(KDy = DKy\). So preprocessing the flipped data equals flipping the preprocessed data. The test stays exact, and the null adds no structure.
  • A fixed projection that is not axis-aligned, \(\pi_Q(y) = (I_d - QQ^\top)y\). The test is still exact, because \(\pi_Q\) is fixed. But \(\pi_Q(Dy) = Dy - QQ^\top Dy\): the second term always lies in the same fixed span of \(Q\), whatever \(D\) is. For the raw estimator, in steps. Step 1: a replicate's rows are \(\pi_Q(Dy) = (I_d - QQ^\top)Dy\), so its \(M\) is the average of \((I_d - QQ^\top)Dyy^\top D(I_d - QQ^\top)\) (transpose of a product, reversed, with \(D^\top = D\) and \((I_d - QQ^\top)^\top = I_d - QQ^\top\)), which is \((I_d - QQ^\top)DMD(I_d - QQ^\top)\). Step 2: average over the random flips. In PCA coordinates \(DMD\) keeps each diagonal entry and multiplies entry \((i,j)\) by the product of two independent random signs, which averages 0. So the flip average of \(DMD\) is \(\Lambda\), the diagonal part of \(M\) in PCA coordinates. Step 3: the replicates therefore centre on \((I_d - QQ^\top)\Lambda(I_d - QQ^\top)\). Unless \(Q\) lies along PCA axes, this is not diagonal in PCA coordinates, and it is the same fixed matrix for every replicate. So the null patterns themselves reproduce, and split-half loses all power.

This happened. The first flip test (variant b, frozen rule, L16 and L28) projected out the massive span. \(\lambda_1\) beat all 200 flips for every estimator (1.4 to 2.1× the flip maximum), but the null split@3 maximum was 0.95 to 0.98, so the split condition could not pass. Verdict: FAIL (paper §4b; theory-v2 §6B).

The measurement (hlens/hs_v9.py, header). A move \(a\) is a unit vector in whitened coordinates; it is applied as \(h_\ell[p]\mathrel{+}=\Sigma^{1/2}a\), a 1σ move. Let \(f\) be the summed log-likelihood of the next 16 tokens (nats). Then

$$ I = f(a+b) - f(a) - f(b) + f(0),\qquad I_{\text{trunk}} = f(a+b) - f_{\text{add}},\qquad I_{\text{soft}} = I - I_{\text{trunk}}, $$

where \(f_{\text{add}}\) is \(f\) evaluated on the pre-norm last-layer state \(h_a + h_b - h_0\) (the sum of the two single-move effects on the trunk). So \(I_{\text{trunk}}\) is the part of the interaction already present in the residual stream, before the final norm and softmax. By the rectangle identity (Level 12, Lemma 3), \(I\) equals the Hessian of \(f\) averaged over the rectangle the two moves span: it is a second-order quantity at natural scale, with no Taylor truncation.

This level is the place every earlier idea gets used. A map back down the ladder:

Exercise 15.8. Prove that a Σ-orbit twin \(Q = D\,\mathrm{EX}\) (\(D\in\mathcal D\)) removes exactly the same raw variance as EX from data with covariance \(\Sigma\).

Show answer

Work in whitened coordinates, where the centred data \(z = \Sigma^{-1/2}(h - \mu)\) have covariance \(I_d\). Removing the subspace spanned by the orthonormal columns of EX takes away \(\mathrm{EX}\,\mathrm{EX}^\top z\), which in raw units is \(\Sigma^{1/2}\mathrm{EX}\,\mathrm{EX}^\top z\) (a.u.).

Write \(A = \Sigma^{1/2}\mathrm{EX}\,\mathrm{EX}^\top\), so the removed part is \(Az\). Its mean squared size, step by step.

Step 1: squared length as a trace. For any vector, \(\lVert Az\rVert^2 = (Az)^\top(Az)\), a single number. A single number is its own trace, and the trace of a product of two matrices does not change if their order is swapped (the cyclic property; check with a column \((1,2)^\top\) and a row \((3,4)\): the 2×2 product has trace \(3 + 8 = 11\), the 1×1 product is \(3 + 8 = 11\)). So \(\lVert Az\rVert^2 = \operatorname{tr}\big((Az)(Az)^\top\big) = \operatorname{tr}(Azz^\top A^\top)\).

Step 2: average. The trace is a sum of entries, so it passes through the average (linearity), and \(A\) is fixed: \(\mathbb{E}\lVert Az\rVert^2 = \operatorname{tr}(A\,\mathbb{E}[zz^\top]\,A^\top) = \operatorname{tr}(AA^\top)\), because \(\mathbb{E}[zz^\top] = I_d\).

Step 3: multiply out. \(A^\top = \mathrm{EX}\,\mathrm{EX}^\top\Sigma^{1/2}\) (transpose of a product, reversed; both \(\mathrm{EX}\,\mathrm{EX}^\top\) and \(\Sigma^{1/2}\) are symmetric). So \(AA^\top = \Sigma^{1/2}\mathrm{EX}\,(\mathrm{EX}^\top\mathrm{EX})\,\mathrm{EX}^\top\Sigma^{1/2} = \Sigma^{1/2}\mathrm{EX}\,\mathrm{EX}^\top\Sigma^{1/2}\), because the columns of EX are orthonormal: \(\mathrm{EX}^\top\mathrm{EX} = I_5\).

Step 4: cycle the trace. Move \(\Sigma^{1/2}\mathrm{EX}\) from the front to the back: \(\operatorname{tr}(\Sigma^{1/2}\mathrm{EX}\,\mathrm{EX}^\top\Sigma^{1/2}) = \operatorname{tr}(\mathrm{EX}^\top\Sigma^{1/2}\Sigma^{1/2}\mathrm{EX}) = \operatorname{tr}(\mathrm{EX}^\top\Sigma\,\mathrm{EX})\) a.u.².

Step 5: the twin. Replace EX by \(Q = D\,\mathrm{EX}\). Its columns are still orthonormal: \(Q^\top Q = \mathrm{EX}^\top D^\top D\,\mathrm{EX} = \mathrm{EX}^\top D^2\mathrm{EX} = I_5\), since \(D^\top = D\) and \(D^2 = I_d\). So Steps 1 to 4 apply and give \(\operatorname{tr}(Q^\top\Sigma Q) = \operatorname{tr}(\mathrm{EX}^\top D\Sigma D\,\mathrm{EX}) = \operatorname{tr}(\mathrm{EX}^\top\Sigma\,\mathrm{EX})\), because \(D\Sigma D = \Sigma\). The removed raw variance is identical.

Toy check with \(d = 2\), one direction: \(\Sigma = \operatorname{diag}(4, 1)\), \(\mathrm{EX} = (0.6, 0.8)\), and \(D\) flipping axis 2 so \(Q = (0.6, -0.8)\). Then \(\mathrm{EX}^\top\Sigma\,\mathrm{EX} = 4\times0.36 + 1\times0.64 = 2.08\), and \(Q^\top\Sigma Q = 4\times0.36 + 1\times0.64 = 2.08\). Same.

Exercise 15.9. The first flip test (variant b) projected out a fixed, non-axis-aligned span \(Q\). Explain why the test was still exact but its split-half condition had no power, and why v5's axis-aligned drop avoids this.

Show answer

Exact: \(\pi_Q\) is a fixed function, so the flipped-then-projected replicates are still exchangeable with the projected real data. No power: each replicate's operator is \((I_d - QQ^\top)DMD(I_d - QQ^\top)\). Averaged over flips this is \((I_d - QQ^\top)\Lambda(I_d - QQ^\top)\), the same non-diagonal matrix for every replicate. Its patterns are reproducible, so the null split@3 is high (0.95 to 0.98 measured) and the observed split cannot beat it. An axis-aligned mask \(K\) commutes with every \(D\), so masking adds no fixed off-diagonal structure: \(KDMDK = DKMKD\), whose flip average is diagonal.

Exercise 15.10. v5 passed, the twin causal test failed, and v9 passed. Explain why these three results do not contradict each other.
